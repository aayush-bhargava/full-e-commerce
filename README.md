   # Project Name

A modern web application built with Next.js (App Router), optimized for performance, scalability, and developer experience.
E-commerce website based on spiritual products.
(for a client)

---

## Description

This project is built using Next.js and bootstrapped with `create-next-app`.

It provides:

- Server-side rendering (SSR)
- Static site generation (SSG)
- Optimized font loading via `next/font`
- Fast refresh in development
- Production-ready build configuration

---

## Tech Stack

- Next.js 14 (App Router)
- React
- TypeScript
- next/font (Geist)
- Node.js

---

## Installation

### Requirements

- Node.js 18+
- npm / yarn / pnpm / bun

### Clone Repository

```bash
git clone https://github.com/your-username/full-e-commerce.git
cd full-e-commerce
```
## Install Dependencies
```
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

## Usage
### Run Development Server
```
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

### Application runs at:

```
http://localhost:3000
```

### Edit:
```
app/page.tsx

-- Changes auto-refresh during development.
```

## Project Structure
``` 
app/              # App Router pages and layouts
public/           # Static assets
styles/           # Global styles
```

### Build for Production
```
npm run build
npm start
```
### Lint
```
npm run lint
```
### Deployment

```
Recommended: Deploy on Vercel.
```
